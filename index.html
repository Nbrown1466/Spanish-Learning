Present subjunctive inherits the YO formTake present-indicative yo, remove -o, then add opposite-vowel endings.
tengo → teng- → tenga
vengo → veng- → venga
conozco → conozc- → conozca
digo → dig- → diga
Imperfect subjunctive inherits the preteriteTake the ellos preterite, remove -ron, then add the -ra family.
tuvieron → tuvie- → tuviera
dijeron → dije- → dijera
pudieron → pudie- → pudiera
Overlap familiesOne verb can belong to several branches at once.
tener = -GO + E→IE + tuv- + tendr-
venir = -GO + E→IE + vin- + vendr-
decir = digo + E→I + dij- + dir-
Best way to study this: choose one anchor verb per family. For example: tener for -GO, pensar for E→IE, poder for O→UE, pedir for E→I, and then learn the preterite/future stems as separate branches. The important idea is that a verb can sit in more than one family.
